AIRA AI PROTOTYPE
=================
This is a simple phone-friendly AI chat UI prototype.

HOW TO TEST
1. Open index.html in a browser or a mobile HTML editor/preview app.
2. Type a message and press Send.
3. The prototype gives a demo response.

IMPORTANT
This prototype does NOT contain a real AI API key. Never put a private API key directly into a public frontend app.

NEXT STEP
Connect a secure backend to an AI API, then deploy the app as a website/PWA or package it as an Android app.
